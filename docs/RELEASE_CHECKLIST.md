# 发布验收清单

## 自动检查

- Windows / Python 3.12 全量单元测试通过。
- Ruff 关键错误检查通过。
- CI 生成覆盖率报告，检查本次修改涉及的分支是否被覆盖。
- 打包任务只找到一个 `*-online-setup.exe`，Release 只上传该启动器。
- GitHub Release 页面显示的资产摘要与本地下载文件一致。

## 实机验收

以下项目需要连接《鸣潮》Windows 客户端人工验证，不能由 CI 代替：

- 1280×720、1920×1080 和一个更高的 16:9 分辨率均能连接游戏窗口。
- 前台与后台模式分别验证点击、轻触、长按、连续点击和 F10 紧急停止。
- 椰果轴在正常播放、切人视觉同步、目标丢失、重新索敌和等待超时后行为正确。
- 目标丢失时所有长按输入均被释放；重新锁定后不会集中补发动作。
- 手动更新、自动更新至正式版、自动更新至预发布版分别完成一次升级验证。
- 从上一正式版升级后，用户设置和自定义角色代码仍然保留。

记录测试游戏版本、应用版本、Windows 版本、分辨率、帧率和结果。任一关键路径失败时不要创建正式版 tag。

## 签名与发布

- 有 Authenticode 证书时，在上传前对启动器签名并验证签名；没有证书时保持 README 的“未知发布者”提示。
- 只有 `master` CI 成功且实机验收通过后，才创建新的 `vX.Y.Z` tag。
- tag 会触发同步更新仓库和 GitHub Release；不要在同一提交上创建多个发布 tag。
